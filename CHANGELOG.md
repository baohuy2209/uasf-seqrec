# Changelog

## 1.0.0 — release preparation, 2026-11-14

- Promote the completed F2 study and frozen Beauty Test results to the main README.
- Add MIT licensing, software citation metadata, and third-party notices.
- Add a compact, checksummed summary bundle and a CPU-only verifier/exporter.
- Add a portable reproduction profile while retaining the original scientific configs.
- Allow the logger to snapshot source ZIPs without inventing Git provenance.
- Replace a private-data-dependent path test with a small fixture.
- Exclude local datasets, item metadata, runtime runs, and historical reports from
  the public source tree while retaining those files locally.

Model architecture, losses, split policy, masks, seeds, checkpoint-selection rules,
and the original frozen study outputs are unchanged. This preparation does not
create a Git tag, publish a release, or execute a new research experiment.
