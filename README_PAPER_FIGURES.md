# TAIMMA paper figures

Python/Matplotlib only. These scripts load neither checkpoints nor training/evaluation runners.

## Figures 2 and 3 — actual run CSVs

From the repository root, with its Python environment activated:

```bash
python scripts/visualize_memo0711.py \
  --run-root runs/memo0711_v3 \
  --output results/paper_figures_memo0711_v3
```

The same one-line command works in PowerShell:

```powershell
python scripts/visualize_memo0711.py --run-root runs/memo0711_v3 --output results/paper_figures_memo0711_v3
```

- Figure 2, `source_effects.pdf`: reads 135 archived `per_user_test.csv` files, following each job's `completed.json` checkpoint directory. Recomputes mean NDCG@10 and checks each value against the target rank. Add = single-source minus ID; Drop = CBT minus without-source. Both are differences between separately trained configurations. Error bars are sample SD of three paired-seed differences, not CI. The vertical display scale is NDCG×100, not relative percentage improvement.
- Figure 3, `robustness_three_datasets.pdf`: reads the 90 records in each dataset's `robustness.csv`. Every dataset/model/source/rate combination must contain seeds 42/43/44 exactly once. Lines are seed means and bands are ±1 sample SD. Each panel removes one source only; rates refer to originally available items. Y-axes differ across panels.
- `source_effects.csv`, `robustness_levels.csv`: generated figure-source summaries; no hard-coded result numbers.
- `figure_manifest.json`: exact input CSV SHA256 checksums, seeds, metric scope and script checksum. The input files remain unchanged.
- SVG and PNG companions are also exported. PDF is the manuscript asset.

The script requires NumPy and Matplotlib already used by the project. It fails for missing files, incomplete grids, duplicate users, unmatched user/target cohorts, non-finite metrics or inconsistent rank/NDCG records. It will not silently substitute old runs or open the quarantined UASF test evaluation. Diagnostic B test CSVs already present are the only test inputs.

## Figure 1 — code-based architecture draft

After checking Figures 2 and 3:

```bash
python scripts/draw_uasf_overview.py --output results/paper_figures_memo0711_v3
```

This produces `uasf_architecture.pdf`, `.svg`, and `.png`. It is a deterministic editable schematic draft based on `early_fusion.py`, `selective_fusion.py`, and `memo0711.py` (`SeparateID`). It is not generated by an image model and is not experimental evidence. Authors should review/edit it for the conference's policy on AI-assisted diagrams. It shows the gate affecting both history/candidates, target-free ungated reference features, and the separate same-seed Train-base ID fallback. Source dropout trains S1; only the gate trains in S3. Thresholding applies at evaluation, not in continuous gate training.

## Export and LaTeX

All exports follow the requested crop:

```python
fig.savefig(path, format="pdf", bbox_inches="tight", pad_inches=0.02)
```

Copy the three PDF files into the manuscript's `figs/` directory. The filenames match the revised manuscript. Use `\includegraphics[width=\linewidth]{figs/source_effects.pdf}` and the equivalent names for the other figures. Check final-size text and the 12–15-page LNCS budget after compiling with the real bibliography.
